Configurar sincronização

Para sincronizar entre dispositivos, o app usa o Firebase do Google — gratuito e sem limite para uso pessoal. Siga os passos abaixo uma única vez.

1
Acesse console.firebase.google.com e clique em Criar projeto. Dê um nome (ex: gestao-fin) e desative o Google Analytics.
2
Dentro do projeto, clique em Realtime Database no menu lateral → Criar banco de dados → escolha Iniciar no modo de teste → Ativar.
3
Copie a URL do banco que aparece no topo (formato: https://SEU-PROJETO-default-rtdb.firebaseio.com).
4
Cole a URL abaixo e clique em Conectar. Pronto — todos os dispositivos que usarem a mesma URL estarão sincronizados.
